# Vasuki Business Studio

A premium business workspace for quotations, catalogs, clients, follow-ups, analytics and AI-assisted communication.

## Stack
- Next.js 16 + React 19 + TypeScript
- Node.js
- Premium responsive custom UI
- Python FastAPI backend scaffold
- Render Blueprint (`render.yaml`)

## Local setup
```bash
git clone https://github.com/hemshankar642-source/vasuki-business-studio.git
cd vasuki-business-studio
npm install
npm run dev
```

Open http://localhost:3000

## Update from CMD
```bash
git add .
git commit -m "Update app"
git push
```

## Render
Create a Blueprint from this repository. `render.yaml` defines the Node web app and Python API.
